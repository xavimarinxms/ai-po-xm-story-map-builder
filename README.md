# Story Map Builder — by Xavi Marín

Visual user story mapping tool with 3 levels: Activities → Tasks → Stories, organized by release swimlanes. Drag & drop, export to CSV.

## Stack
- Next.js 14 (App Router) + TypeScript
- Tailwind CSS
- @hello-pangea/dnd (drag & drop)
- No backend — runs entirely in the browser

## Setup

```bash
npm install
npm run dev
```

No environment variables needed.

## Deploy to Vercel

```bash
vercel deploy
```
